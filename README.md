# QART AI

**Intelligence for Quantum Systems.**

QART AI is an AI-native quantum-control research platform. The current public build is a simulation/digital-twin environment; it is not a claim of a fabricated quantum processor.

## Product
- **QART Lab** — interactive 16-qubit digital-twin experiments
- **QART Sentinel** — detects drift/noise degradation
- **QART Pilot** — bounded adaptive interventions
- **QART Memory** — per-qubit telemetry history
- **Safety Gate** — deterministic boundary between adaptive intelligence and device control

## Run
Open `index.html` directly, or serve this repository with any static web server.

## Research status
Software simulation → HIL architecture → FPGA RTL → board/RF validation → cryogenic research device.

All benchmark claims must state whether they come from simulation, host software, FPGA, or physical hardware.
