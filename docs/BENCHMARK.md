# QART Benchmark Protocol v1

The benchmark runs **Baseline** and **QART** with the same seed, cycle count and injected drift magnitude.

Reported:
- final mean fidelity
- final availability
- minimum observed qubit fidelity
- intervention count
- deltas (QART - Baseline)

This is a software digital-twin benchmark. It is not evidence of quantum advantage, FPGA timing, or physical-QPU performance.
