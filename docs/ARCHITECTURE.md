# QART AI architecture

QART separates long-horizon adaptive intelligence from deterministic device authority.

1. QART Memory — telemetry history
2. Sentinel — degradation detection
3. Digital Twin — predictive model
4. Pilot — bounded intervention proposal
5. Safety Gate — deterministic validation
6. FPGA/RT boundary — fail-closed control
7. QPU/device — simulation today; laboratory hardware later

## Claim boundary
The public web lab is explicitly a digital-twin simulation. Physical performance will be reported only from the corresponding physical layer.
